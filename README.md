# Tienda para niños con interfaz responsive (Roblox)

Pieza 2 del portafolio. Una tienda dentro de un taller de juguetes: catálogo con categorías, compra con las monedas del juego, interfaz que funciona en celular, tableta, PC y mando.

**Cómo se hizo:** el código se desarrolla dirigiendo a Claude (IA) y se verifica con pruebas en Roblox Studio. No está escrito a mano.

**Estado:** en construcción. Este archivo se completa al terminar (qué está probado y qué no, archivos, cómo probarlo).

## Código reutilizado de la pieza 1

Copiado y sin cambios de lógica desde `roblox-game`: `ProfileStore` (librería de terceros, ver `THIRD_PARTY.md` y `licenses/`), `DataService`, `CurrencyService`, `InventoryService`, `Validation`, `DataTemplate` y `DataReplicator`. Se quitó lo que solo servía para el ícono de guardado de la pieza 1.
